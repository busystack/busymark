# Changelog

## 0.8.0

- Add standard HTML audio authoring and playback for Markdown, with local files,
  source fallback, permission-gated HTTPS media, and portable HTML export.
- Add Read aloud and Generate audio, using a semantic projection of the current
  document and separate speech preferences.
- Add Speech settings for local voices, secure provider credentials, narration
  rules and WAV output.
- Move the primary Linux build and CI baseline to Ubuntu 26.04 and the shipping
  Snap recipe to core26.
